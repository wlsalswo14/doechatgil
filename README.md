# 되찾길 — 올림픽공원 다국어 분실물 길잡이

> 한국체육산업개발(주) 「2026년도 공공데이터 활용 경진대회」 활용사례 출품작 (1단계 MVP)

**시연:** https://wlsalswo14.github.io/doechatgil/

올림픽공원에서 물건을 잃어버린 사람이 **언제·어디서·무엇을**만 입력하면 다음을 알려 줍니다.

1. **지금 있을 곳** — 공고 게시 속도와 경찰서 이관 일정으로 단계를 판정합니다. 단계는 `등록 대기 → 안내센터 보관 → 이관 가능 구간 → 경찰서 이관` 4단계입니다.
2. **그날의 행사** — 분실한 날 그 장소에서 열린 공연을 찾아 주최·문의처를 보여 줍니다.
3. **공원 공고 후보** — 표준 품목 사전으로 표기가 달라도 찾습니다. 예: "핸드폰" → "휴대폰", "AirPods" → "블루투스 이어폰".
4. **한국어 확인 카드** — 안내센터 직원에게 보여 줄 카드입니다. 공고에 없는 색상·특징을 정리합니다.
5. **근거 기반 안내(한·영)** — 기관 FAQ 원문에서만 답하고 출처 링크를 붙입니다. 근거가 부족하면 답하지 않습니다.

회원가입, 서버, DB가 없습니다. 개인정보를 수집하거나 전송하지 않습니다.

## 데이터

| 데이터 | 출처 | 수집 방식 |
|---|---|---|
| 유실물 공고·이관 공지 | 한국체육산업개발 「올림픽공원 및 미사경정공원 유실물 정보」 | `KCISA_KEY`가 있으면 오픈API, 없으면 같은 원천인 공식 유실물 게시판 |
| 공연·행사 일정(주최·문의처) | 올림픽공원 공연·행사 일정 (대관·공연정보 원천) | 공식 사이트 공개 JSON |
| 자주 묻는 질문 | 한국체육산업개발 자주 묻는 질문 | 공식 게시판, 영어는 원문을 번역해 검수 |
| 경찰청 습득물 2종 | 경찰청 습득물정보·포털기관 습득물정보 조회 서비스 | `DATA_GO_KR_KEY` 활용 승인 시 |

출처: 한국체육산업개발(주), 공공누리 제1유형.

## 구조

```
collector/collect.py     수집·정규화 (표준 라이브러리만 사용)
collector/dictionary.py  품목 사전(경찰청 분류 기준)과 장소 사전
analysis/stats.py        기획서 수치 재현 → analysis/stats.json
site/                    정적 웹 (index.html, style.css, app.js, data/*.json)
```

## 실행

```bash
python -I collector/collect.py      # site/data 갱신
python -I analysis/stats.py         # 분석 수치 재계산
python -m http.server 8765 --directory site
```

API 키는 저장소 Secrets(`KCISA_KEY`, `DATA_GO_KR_KEY`)에만 둡니다.

시연 사이트는 `site/` 폴더를 `gh-pages` 브랜치로 배포합니다. 데이터 기준 시각은 화면 아래 "마지막 갱신"에 표시됩니다.
